# 📚 Інструкція по встановленню проекту News-Lite

## Вимоги

Перед початком переконайтесь, що на вашому комп'ютері встановлено:

- **Node.js** версія 18+ ([https://nodejs.org/](https://nodejs.org/))
- **npm** або **yarn** (йде з Node.js)
- **PostgreSQL** 12+ ([https://www.postgresql.org/download/](https://www.postgresql.org/download/))
- **Git** ([https://git-scm.com/](https://git-scm.com/))

## Крок 1: Клонування репозиторію

Відкрийте термінал (Command Prompt, PowerShell або Git Bash) та виконайте команду:

```bash
gh repo clone AlexDm125/news-lite
```

Якщо ви не маєте встановлений GitHub CLI, можна використати:

```bash
git clone https://github.com/AlexDm125/news-lite.git
```

Далі перейдіть до папки проекту:

```bash
cd news-lite
```

## Крок 2: Встановлення залежностей

Виконайте команду для встановлення всіх необхідних npm пакетів:

```bash
npm install
```

або якщо ви використовуєте yarn:

```bash
yarn install
```

## Крок 3: Налаштування змінних окруження

1. Скопіюйте файл `.env.example` в новий файл `.env.local`:

```bash
cp .env.example .env.local
```

На Windows (PowerShell):
```powershell
Copy-Item .env.example -Destination .env.local
```

2. Відкрийте файл `.env.local` в текстовому редакторі та заповніть всі необхідні значення

Детальний опис кожної змінної див. нижче в розділі **Змінні окруження**

## Крок 4: Налаштування бази даних

### 4.1 Створення бази даних PostgreSQL

Відкрийте psql (PostgreSQL CLI) та виконайте:

```sql
CREATE DATABASE news_lite;
```

### 4.2 Міграція бази даних Prisma

Виконайте команду для застосування всіх міграцій:

```bash
npx prisma migrate deploy
```

## Крок 5: Запуск проекту

### Для розробки (development mode):

```bash
npm run dev
```

Проект буде доступний за адресою: **http://localhost:3000**

### Для production:

```bash
npm run build
npm start
```

## Кроки розробки та виконання команд

- **`npm run dev`** - запуск в режимі розробки з live reload
- **`npm run build`** - побудова проекту для production
- **`npm start`** - запуск в режимі production
- **`npm run lint`** - перевірка коду на помилки

## 📋 Змінні оточення

Створіть файл `.env.local` з такими змінними:

```env
# === DATABASE ===
DATABASE_URL="postgresql://user:password@localhost:5432/news_lite"

# === NEXTAUTH ===
AUTH_SECRET="your-secret-key-here-at-least-32-characters"

# === CLOUDINARY ===
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME="your-cloud-name"
CLOUDINARY_API_KEY="your-api-key"
CLOUDINARY_API_SECRET="your-api-secret"

# === APP ===
NEXTAUTH_URL="http://localhost:3000"
NODE_ENV="development"
```

**Детальне описання кожної змінної**:

| Змінна | Опис | Приклад |
|--------|------|---------|
| `DATABASE_URL` | URL підключення до PostgreSQL | `postgresql://postgres:password@localhost:5432/news_lite` |
| `AUTH_SECRET` | Секретний ключ для шифрування JWT токенів (мін. 32 символи) | `supersecretkey123456789012345678` |
| `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` | Ім'я вашого Cloudinary акаунту | `my-cloud-name` |
| `CLOUDINARY_API_KEY` | API ключ Cloudinary | `123456789` |
| `CLOUDINARY_API_SECRET` | API секрет Cloudinary | `abcdefghijklmnopqrst` |
| `NEXTAUTH_URL` | URL вашого додатку | `http://localhost:3000` |
| `NODE_ENV` | Середовище виконання | `development` або `production` |

## 🔧 Налаштування Cloudinary

1. Перейдіть на [https://cloudinary.com/](https://cloudinary.com/) та зареєструйтесь
2. Увійдіть в Dashboard
3. Скопіюйте:
   - **Cloud Name** → `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`
   - **API Key** → `CLOUDINARY_API_KEY`
   - **API Secret** → `CLOUDINARY_API_SECRET`
4. Вставте ці значення в `.env.local`

## 🔐 Генерування AUTH_SECRET

Щоб генерувати безпечний секретний ключ, виконайте в Node.js:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Скопіюйте результат і вставте в `AUTH_SECRET`

## 🐛 Розв'язання проблем

### Помилка: "Cannot find module 'next-auth'"
```bash
npm install
```

### Помилка: "connection refused" (база даних)
- Переконайтесь, що PostgreSQL запущена
- Перевірте правильність `DATABASE_URL`

### Помилка: "AUTH_SECRET is not set"
- Заповніть `AUTH_SECRET` в `.env.local`

### Порт 3000 уже в користуванні
```bash
npm run dev -- -p 3001
```
